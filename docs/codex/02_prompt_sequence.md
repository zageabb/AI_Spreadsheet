# Prompt Sequence

## Sequence
1. Master scaffold
2. UI improvements
3. Formula engine
4. JSON storage
5. PostgreSQL
6. Authentication and permissions
7. Collaboration server
8. Email notifications
9. Excel import/export
10. Tests and hardening
11. Final cleanup

## Why this order
- The scaffold creates the stable foundation
- The UI and formula engine make the app usable
- Storage is refined before server/database work
- Auth and sharing are added before collaboration
- Import/export is improved after the workbook model is stable
- Hardening comes near the end
